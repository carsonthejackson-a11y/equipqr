## Copy decisions

- Story paragraphs are verbatim from the previous `about/page.tsx` (README: "paragraphs
  from `about/page.tsx` verbatim"), so the page wins where the design differs:
  - P1: page "…restaurants — and for a long time, a big chunk…" vs design
    "…restaurants, and for a long time a big chunk…".
  - P3: page "…exact model — no app, no account…" vs design "…exact model. No app, no
    account…".
  - P4: page "…a technician — not a product team — would…" vs design "…a technician,
    not a product team, would…".
  - The page used curly apostrophes/quotes (’ “ ”); the design uses straight ones.
    Kept the curly glyphs, and used the same curly apostrophe in the hero lead
    ("technician’s") so the page is typographically consistent.
- The pull line "The truck rolls that are left are the ones that actually need a
  truck." previously opened paragraph 4; it now stands alone as the pull line and
  paragraph 4 starts at "That’s the entire premise…" (as in the design).
- The CTA copy hard-codes "14 days" because the previous page did not interpolate
  `TRIAL_DAYS` (BRIEF §3.5 only asks to keep interpolation where it already exists).

## Divergences

- Fact-row icons are 22px per the WS10 task spec (feature-row leader size); the
  design draws them at 18px. Change `size={22}` → `size={18}` if the orchestrator
  prefers the design value.
- No `.eq-rule` dividers: `About.dc.html` has none between its three sections.
- Section padding: `Section` only knows the README rhythm, so the hero bottom and
  story top paddings are overridden via `className` to match the design's tighter
  hero → story spacing.
