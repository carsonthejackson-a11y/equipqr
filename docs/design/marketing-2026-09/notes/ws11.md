# WS11 — Contact

Files: `contact/page.tsx`, `contact/contact-form.tsx`, `contact/actions.ts`,
`contact/validation.ts` (new).

- Page per README §7: hero, sticky left column (Email us directly / Response time
  cards, FAQ note), form panel on the right.
- `validation.ts` holds the shared strings and the pattern check so the client
  pre-check and the server action agree ("Please fill in your name, email, and a
  message." / "That email address doesn’t look right."). It also holds
  `ContactState` / `initialContactState`: a `"use server"` module may only export
  async functions, and the agent that built this page had left the constant in
  `actions.ts`, which made every submit throw in dev. Moved by the orchestrator.
- Client flow: `onSubmit` validates and `preventDefault()`s on failure, the alert
  clears on any change, pending shows "Sending…", success swaps the form for the
  status block rendered from `state.message` ("Thanks, we'll get back to you
  shortly.", BRIEF §3.5); "Send another" remounts the form with a new key.
- Verified with Playwright: empty submit → required message; typing clears it;
  bad email → email message; valid submit → server response (the Resend
  not-configured error in this environment).
