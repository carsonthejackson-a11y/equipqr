## `legal.tsx` API

- `LegalLayout({ title, description, lastUpdated, sections, showNotice = true, seeAlso })`
  - `sections: { id, title, body: ReactNode }[]` — `body` is one or more
    `<p>` / `<ul>` blocks; the layout spaces them 12px apart and styles
    `ul` (`pl-[22px] gap-1.5`), `strong` (500, `text-eq-text`) and `a`
    (accent, underline offset 3px, hover accent-300) via descendant selectors,
    so page bodies stay plain markup (`<a>` for `mailto:`, `Link` for routes).
  - `seeAlso: { href, label }[]` — the "See also the A and B." line under the
    contents list. Terms → Privacy Policy + Security; Privacy → Terms of
    Service + Security.
  - `showNotice` — the bottom "Note: … not legal advice" panel (design
    `data-props` default `true`).
- `Code` — the inline `/e/` chip: `ui-monospace, SFMono-Regular, Menlo,
  monospace` at 0.9em (README "Typography"; the app's `font-mono` is Geist
  Mono, so the stack is an arbitrary value), surface fill, neutral-900 border,
  5px radius.
- Types `LegalSection`, `LegalLink`, `LegalLayoutProps` exported.
